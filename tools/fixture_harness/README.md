# Fixture screenshot harness

Screenshots of the fragment's `?kgdev=<state>` fixtures without a Hub login. The compute service's plugin
routes answer 403 without the Hub JWT, so the harness mounts a copy of `ui.html` with the Hub's public CSS
and a stubbed `window.PLUGIN_API` whose `GET /config` answer is a `config.json` generated by the plugin
itself against a scratch home; every other call answers `{}` and no job can start (the fixtures disable
every action).

```powershell
# 1. The config payload (the repo venv; the dev manifest tier unless KAGGLE_CLASSIFICATION_MANIFEST_BASE_URL says otherwise)
uv run python tools\fixture_harness\make_config.py "$env:TEMP\kgc-fixture-home"

# 2. The shots (an interpreter with playwright; Edge is used as the browser channel, no download)
python tools\fixture_harness\shoot.py docs\ui-review\after-rc12 state1,state2,state4,state6
```

The fixture names are listed at the top of the fragment's script (`?kgdev=` comment). `shoot_index.json`
beside the shots records, per state, the banner, the checks line and whether it is open, the table rows,
the preflight verdict, the splits block, any console error and whether an em dash reached the page.
`docs/ui-review/` is untracked review material.
