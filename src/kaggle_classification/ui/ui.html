1 Import
Starter kit

Downloads the competition images from the 3LC content network to the machine running the compute service, then verifies every file against the published manifest.

Saves to on the service machine. An interrupted download keeps its finished parts and resumes.

Downloads the newer kit beside the one you already have, then verifies every file against the published manifest. 2 Train

      
Trains the competition baseline on your imported tables and
        records verified provenance (the locked from-scratch contract) on the 3LC Run.

    

    

      
      

        
        

          

          
Enforced server-side; identical architecture, init rule and resolution for every participant.

Locked to the revision Import created: every run is scored against
              the same validation split.

          

        

        

        

          
          
Trains on the train table's newest revision (.latest()),
            picking up your label edits from the Dashboard. On for every new run; only "Use these
            settings" on a previous run pins that run's revision.

        


        

        
Training parameters

Images per training step. Raise it until GPU memory runs out;
              lower it on CUDA out-of-memory. 16 fits any card at px.
              

            

          

          

            
            
            
Initial learning rate for Adam. Higher learns faster but can diverge;
               

            

          

          

            
            
            
L2 penalty on the weights (the optimizer's weight_decay). 0 is the
              baseline; a small value regularises a from-scratch model. 

            

          

          
          

            
            

              
              
            

            
Which optimizer updates the weights. Switching applies that optimizer's
              usual learning rate above when the field still holds the previous default.

          

          

            
            

              
              
            

            
How the learning rate changes over the run: the kit\'s step decay, a
              cosine decay to zero, or constant.

                    accelerator fails at start, the run retries on CPU and says so. The run header names
                    the reason: cuda (auto), cpu (forced in Advanced) or
                    cpu (fallback: …). Use these settings never copies a run's device.
